## 🚀 Featured Projects

### 🔷 3D Semantic Scene Understanding from Monocular Video

A computer vision and 3D reconstruction framework designed to generate structured spatial representations from monocular RGB video.

**Key Contributions:**

- Integrated **YOv8-based object detection, depth estimation, semantic segmentation, and COLMAP-based 3D reconstruction**.
- Generated structured spatial representations using only monocular RGB video.
- Evaluated geometric and semantic performance using **reprojection error, temporal drift, and object-localization metrics**.
- Achieved a **mean reprojection error of 0.87 pixels**.

**Tech Stack:** Python, YOLOv8, OpenCV, COLMAP, PyTorch, Computer Vision

🔗 Repository:  
https://github.com/Ravuri-Jeetu/3D_Semantic-_Scene_Understanding
